Errori di scarto della fattura elettronica: i codici del Sistema di Interscambio

Quando il Sistema di Interscambio scarta una fattura elettronica, la ricevuta di scarto riporta un codice di cinque cifre. In questa pagina trovi tutti i 65 codici previsti per le fatture tra privati, ordinarie e semplificate. Per ognuno c'è il testo ufficiale dell'Agenzia delle Entrate, una spiegazione in parole semplici e il campo del file da controllare.

Aggiornata all'11 novembre 2026

Fonte: Agenzia delle Entrate, Allegato A delle specifiche tecniche della fattura elettronica, versione 1.9.1 (in uso dal 15 maggio 2026), Appendice 1.

I numeri davanti ai campi, per esempio 2.2.1.12, sono quelli che l'Agenzia usa nelle specifiche tecniche per indicare la posizione del campo nel file. Questa pagina spiega i codici: non sostituisce le specifiche né il parere del tuo consulente.

Scrivi il codice nella casella qui sotto per andare alla sua spiegazione.

00001 Nome del file non valido

Testo ufficiale

«Nome file non valido».

Cosa vuol dire

Il nome del file inviato non rispetta la forma prevista dalle specifiche: codice del paese di due lettere, identificativo fiscale (da 11 a 16 caratteri per l'Italia, da 2 a 28 negli altri casi), il carattere «_» e un progressivo di al massimo 5 caratteri tra lettere e cifre. L'estensione è .xml, oppure .xml.p7m per i file firmati in formato CAdES, oppure .zip per i file compressi. Un esempio delle specifiche: IT99999999999_00002.xml.p7m.

Dove guardare nel file

Nel nome del file, non nel contenuto.

Si vede prima dell'invio?

In parte. La forma del nome si controlla a occhio, ma conta il nome con cui il file viene davvero inviato, che può essere diverso da quello della copia che hai sul computer.

Vale per: fatture ordinarie e semplificate.

00002 Nome del file duplicato

Testo ufficiale

«Nome file duplicato».

Cosa vuol dire

Al Sistema di Interscambio è già stato inviato un file con lo stesso nome. Le specifiche dicono che ogni file inviato deve avere un nome diverso da qualsiasi altro file inviato in precedenza.

Dove guardare nel file

Nel nome del file, in particolare nel progressivo dopo il carattere «_».

Si vede prima dell'invio?

No. Il confronto è con i file che il Sistema di Interscambio ha già ricevuto.

Vale per: fatture ordinarie e semplificate.

00003 File troppo grande

Testo ufficiale

«Le dimensioni del file superano quelle ammesse».

Cosa vuol dire

Il file supera la dimensione massima. Le specifiche dicono che il singolo file fattura, che contenga una fattura o un lotto di fatture, non può superare i 5MB.

Dove guardare nel file

Nella dimensione del file.

Si vede prima dell'invio?

Sì: basta guardare la dimensione del file.

Vale per: fatture ordinarie e semplificate.

00100 Certificato di firma scaduto

Testo ufficiale

«Certificato di firma scaduto».

Cosa vuol dire

Riguarda solo i file firmati. Il Sistema di Interscambio verifica il certificato usato per la firma, che non deve risultare scaduto, revocato o sospeso. Qui il certificato risulta scaduto.

Dove guardare nel file

Nella firma del file, non in un campo della fattura.

Si vede prima dell'invio?

In parte. La data di scadenza è scritta nel certificato di firma, ma la verifica che conta è quella del Sistema di Interscambio quando riceve il file.

Vale per: fatture ordinarie e semplificate.

00101 Certificato di firma revocato

Testo ufficiale

«Certificato di firma revocato».

Cosa vuol dire

Riguarda solo i file firmati. Il certificato usato per la firma risulta revocato. Il Sistema di Interscambio lo verifica sulle informazioni messe a disposizione dalle Certification Authority.

Dove guardare nel file

Nella firma del file, non in un campo della fattura.

Si vede prima dell'invio?

No. La revoca non è scritta nel file.

Vale per: fatture ordinarie e semplificate.

00102 Firma elettronica non valida

Testo ufficiale

«La firma elettronica apposta al file non risulta valida».

Cosa vuol dire

Riguarda solo i file firmati. Il controllo serve a garantire che il documento non sia stato modificato dopo la firma. Lo scarto arriva quando il documento ricevuto non corrisponde a quello su cui è stata apposta la firma.

Dove guardare nel file

Nella firma del file, non in un campo della fattura.

Si vede prima dell'invio?

In parte. La corrispondenza tra firma e documento si può verificare sul file, ma l'esito che conta è quello del Sistema di Interscambio.

Vale per: fatture ordinarie e semplificate.

00103 Firma senza riferimento temporale

Testo ufficiale

«Alla firma elettronica apposta al file manca il riferimento temporale».

Cosa vuol dire

Riguarda i file firmati con firma elettronica qualificata. Come riferimento temporale il Sistema di Interscambio intende l'attributo «signing time», che deve essere presente nella firma apposta sul documento. Qui manca.

Dove guardare nel file

Nella firma del file, non in un campo della fattura.

Si vede prima dell'invio?

In parte. Il riferimento temporale sta nella firma e si può leggere, ma la verifica che conta è quella del Sistema di Interscambio.

Vale per: fatture ordinarie e semplificate.

00104 Certification Authority non affidabile

Testo ufficiale

«La CA (Certification Authority) che ha emesso il certificato di firma non risulta nell'elenco delle CA affidabili».

Cosa vuol dire

Riguarda solo i file firmati. Il certificato di firma è stato emesso da un ente che non compare nell'elenco di quelli considerati affidabili.

Dove guardare nel file

Nella firma del file, non in un campo della fattura.

Si vede prima dell'invio?

No. L'elenco delle Certification Authority affidabili non è nel file.

Vale per: fatture ordinarie e semplificate.

00105 Riferimento temporale della firma successivo alla ricezione

Testo ufficiale

«Il riferimento temporale associato alla firma elettronica apposta al file è successivo alla data di ricezione del file».

Cosa vuol dire

Riguarda i file firmati con firma elettronica qualificata. Il momento indicato nella firma («signing time») risulta successivo a quello in cui il Sistema di Interscambio ha ricevuto il file. Le specifiche dicono che non può esserlo.

Dove guardare nel file

Nella firma del file, non in un campo della fattura.

Si vede prima dell'invio?

In parte. Il momento della firma si può leggere, ma il confronto è con la data di ricezione, che si conosce solo dopo l'invio.

Vale per: fatture ordinarie e semplificate.

00106 File compresso vuoto o non leggibile

Testo ufficiale

«Il file compresso è vuoto oppure non è leggibile».

Cosa vuol dire

Riguarda l'invio di più fatture in un file compresso, per il quale l'unico formato accettato è lo ZIP. Il file ZIP inviato non contiene nulla oppure non si riesce ad aprire.

Dove guardare nel file

Nel file ZIP: va aperto per controllare che contenga le fatture.

Si vede prima dell'invio?

Sì: basta aprire il file ZIP.

Vale per: fatture ordinarie e semplificate.

00107 Certificato di firma non valido

Testo ufficiale

«Il certificato di firma non è valido».

Cosa vuol dire

Riguarda solo i file firmati. Le specifiche riportano questo codice tra i controlli sul certificato di firma, insieme a certificato scaduto (00100), revocato (00101) e Certification Authority non affidabile (00104), ma non dicono in quali altri casi il certificato è considerato non valido.

Dove guardare nel file

Nella firma del file, non in un campo della fattura.

Si vede prima dell'invio?

Non lo sappiamo: il testo ufficiale non dà la regola.

Vale per: fatture ordinarie e semplificate.

00200 File non conforme al formato

Testo ufficiale

«File non conforme al formato (nella descrizione del messaggio è riportata l'indicazione puntuale della non conformità)».

Cosa vuol dire

Il contenuto del file non rispetta la struttura prevista dalle specifiche tecniche. La ricevuta di scarto indica il punto preciso in cui il file non è conforme: è la prima cosa da leggere.

Dove guardare nel file

Nel punto indicato dal messaggio della ricevuta di scarto.

Si vede prima dell'invio?

Sì: la struttura si può controllare sul file, confrontandolo con lo schema ufficiale.

Vale per: fatture ordinarie e semplificate.

00201 Troppi errori di formato

Testo ufficiale

«Non è possibile procedere con ulteriori controlli perché gli errori di formato presenti nel file superano il numero massimo previsto (50)».

Cosa vuol dire

Nel file ci sono più di 50 errori di formato, cioè del tipo descritto al codice 00200. In questo caso la ricevuta di scarto non riporta gli errori ulteriori.

Dove guardare nel file

In tutto il file: gli errori di formato sono molti.

Si vede prima dell'invio?

In parte. Che gli errori di formato siano molti si vede dal file; il numero esatto contato dal Sistema di Interscambio no.

Vale per: fatture ordinarie e semplificate.

00300 Identificativo del trasmittente non valido

Testo ufficiale

«1.1.1.2 <IdCodice> non valido».

Cosa vuol dire

Il campo è l'identificativo fiscale di chi trasmette il file. Il Sistema di Interscambio verifica che sia presente in anagrafe tributaria. Il controllo non viene fatto sugli identificativi fiscali assegnati da autorità estere.

Dove guardare nel file

Nei dati di trasmissione: il campo IdCodice (1.1.1.2).

Si vede prima dell'invio?

Solo in parte. Dal file si può rileggere il codice e cercare un errore di battitura. Se è presente in anagrafe lo sa solo il Sistema di Interscambio.

Vale per: fatture ordinarie e semplificate.

00301 Partita IVA del fornitore non valida

Testo ufficiale

Fatture ordinarie: «1.2.1.1.2 <IdCodice> non valido».

Fatture semplificate: «1.2.1.2 <IdCodice> non valido».

Cosa vuol dire

Il campo è l'identificativo fiscale ai fini IVA del cedente o prestatore, cioè di chi emette la fattura. Il Sistema di Interscambio verifica che sia presente in anagrafe tributaria. Il controllo non viene fatto sugli identificativi fiscali assegnati da autorità estere.

Dove guardare nel file

Nei dati del cedente/prestatore: il campo IdCodice (1.2.1.1.2 nelle ordinarie, 1.2.1.2 nelle semplificate).

Si vede prima dell'invio?

Solo in parte. Dal file si può rileggere il numero e cercare un errore di battitura. Se la partita IVA esiste in anagrafe lo sa solo il Sistema di Interscambio.

Vale per: fatture ordinarie e semplificate.

Dove guardare nel file

Nei dati dei rappresentanti fiscali: i campi IdCodice indicati nel testo ufficiale.

Si vede prima dell'invio?

Solo in parte. Dal file si può rileggere il codice e cercare un errore di battitura. Se è presente in anagrafe lo sa solo il Sistema di Interscambio.

00306 Codice fiscale del cliente non valido

Testo ufficiale

Fatture ordinarie: «1.4.1.2 <CodiceFiscale> non valido».

Fatture semplificate: «1.3.1.2 <CodiceFiscale> non valido».

Cosa vuol dire

Il campo è il codice fiscale del cessionario o committente, cioè di chi riceve la fattura. Il Sistema di Interscambio verifica che sia presente in anagrafe tributaria. Le specifiche precisano che questo codice vale solo se in fattura non è stata indicata la partita IVA del cessionario/committente.

Dove guardare nel file

00311 Codice destinatario non valido

Testo ufficiale

«1.1.4 <CodiceDestinatario> non valido».

Cosa vuol dire

Il Sistema di Interscambio controlla che il codice destinatario indicato in fattura esista. Le specifiche dicono che il controllo si fa quando il codice è diverso dal valore di default «0000000» e la partita IVA del cessionario/committente non risulta registrata secondo le modalità previste dalle specifiche stesse.

Dove guardare nel file

Nei dati di trasmissione: il campo CodiceDestinatario (1.1.4).

Si vede prima dell'invio?

No. Se il codice esiste lo sa solo il Sistema di Interscambio. Dal file si può solo rileggere il codice e confrontarlo con quello comunicato dal cliente.

Vale per: fatture ordinarie e semplificate.

00312 Codice destinatario non attivo

Testo ufficiale

«1.1.4 <CodiceDestinatario> non attivo».

Cosa vuol dire

Il codice destinatario indicato in fattura risulta al Sistema di Interscambio non attivo. Le specifiche non aggiungono altro su questo codice.

Dove guardare nel file

Nei dati di trasmissione: il campo CodiceDestinatario (1.1.4).

Si vede prima dell'invio?

No. Lo stato del codice lo conosce solo il Sistema di Interscambio.

Vale per: fatture ordinarie e semplificate.

00313 Codice destinatario «XXXXXXX» usato fuori dal suo caso

Testo ufficiale

Fatture ordinarie: «l'elemento 1.1.4 <CodiceDestinatario> può essere valorizzato con "XXXXXXX" per comunicare i dati di fatture emesse esclusivamente verso soggetti non residenti (1.4.1.1 <IdFiscaleIVA> deve essere valorizzato e 1.4.1.1.1 <IdPaese> deve essere diverso da "IT")».

Cosa vuol dire

Il codice destinatario «XXXXXXX» è riservato alle fatture verso soggetti non residenti. Se lo si usa, in fattura deve esserci l'identificativo fiscale IVA del cessionario/committente e il suo paese deve essere diverso da IT.

Dove guardare nel file

I campi CodiceDestinatario (1.1.4), IdFiscaleIVA del cessionario/committente (1.4.1.1) e il suo IdPaese (1.4.1.1.1).

Si vede prima dell'invio?

Sì: basta leggere i tre campi del file.

Vale per: le specifiche riportano la descrizione per le fatture ordinarie.

00320 Partita IVA e codice fiscale del fornitore non coerenti

Testo ufficiale

Fatture ordinarie: «1.2.1.1 <IdFiscaleIVA> e 1.2.1.2 <CodiceFiscale> non coerenti».

Fatture semplificate: «1.2.1 <IdFiscaleIVA> e 1.2.2 <CodiceFiscale> non coerenti».

Cosa vuol dire

Per il cedente/prestatore sono indicati sia la partita IVA sia il codice fiscale. Il Sistema di Interscambio controlla che siano coerenti tra loro, e qui non lo sono.

Dove guardare nel file

Nei dati del cedente/prestatore: i campi IdFiscaleIVA e CodiceFiscale.

Si vede prima dell'invio?

No. La coerenza tra i due codici si verifica in anagrafe tributaria.

Vale per: fatture ordinarie e semplificate.

00321 Codice fiscale del fornitore non partecipante al gruppo IVA

Testo ufficiale

Fatture ordinarie: «1.2.1.2 <CodiceFiscale> di soggetto non partecipante al gruppo IVA».

Fatture semplificate: «1.2.2 <CodiceFiscale> di soggetto non partecipante al gruppo IVA».

Cosa vuol dire

Riguarda i gruppi IVA. La partita IVA del cedente/prestatore è quella di un gruppo IVA, ma il codice fiscale indicato non è di un soggetto che partecipa a quel gruppo.

Dove guardare nel file

Nei dati del cedente/prestatore: il campo CodiceFiscale (1.2.1.2 nelle ordinarie, 1.2.2 nelle semplificate).

Si vede prima dell'invio?

No. Chi partecipa a un gruppo IVA risulta in anagrafe tributaria, non nel file.

Vale per: fatture ordinarie e semplificate.

00322 Manca il codice fiscale del fornitore con partita IVA di gruppo

Dove guardare nel file

Si vede prima dell'invio?

No. Dal file si vede se il codice fiscale manca, ma non se la partita IVA è di un gruppo IVA.

Vale per: fatture ordinarie e semplificate.

00323 Partita IVA del fornitore cessata da oltre 5 anni

Cosa vuol dire

00327 Codice fiscale del gruppo IVA al posto di quello del partecipante

Testo ufficiale

Fatture ordinarie: «1.4.1.2 <CodiceFiscale> di gruppo IVA non riferito ad un partecipante, in assenza di <IdFiscaleIVA> di gruppo IVA».

Fatture semplificate: «1.3.1.2 <CodiceFiscale> di gruppo IVA non riferito ad un partecipante, in assenza di <IdFiscaleIVA> di gruppo IVA».

Cosa vuol dire

Riguarda i gruppi IVA ed è un controllo introdotto con la versione 1.9.1 delle specifiche. Lo scarto avviene quando manca la partita IVA del cessionario/committente e il codice fiscale indicato è quello del gruppo IVA e non di una società che vi partecipa. Le specifiche dicono che va indicato il codice fiscale della società partecipante al gruppo.

Dove guardare nel file

Nei dati del cessionario/committente: il campo CodiceFiscale (1.4.1.2 nelle ordinarie, 1.3.1.2 nelle semplificate).

Si vede prima dell'invio?

No. Che un codice fiscale sia di un gruppo IVA risulta in anagrafe tributaria, non nel file.

Il campo TipoDocumento (2.1.1.1) e, nei dati del cedente/prestatore, il campo IdPaese (1.2.1.1.1).

Si vede prima dell'invio?

Sì: basta leggere i due campi del file.

Vale per: solo le fatture ordinarie.

00474 Righe con aliquota IVA a zero in un'autofattura per splafonamento

Testo ufficiale

«per il valore indicato nell'elemento 2.1.1.1 <TipoDocumento> non sono ammesse linee di dettaglio con l'elemento 2.2.1.12 <AliquotaIVA> contenente valore zero».

Cosa vuol dire

Le specifiche dicono che nel tipo documento «autofattura per splafonamento» tutte le righe devono avere un'aliquota IVA diversa da zero. Qui almeno una riga ha aliquota zero.

Dove guardare nel file

Il campo TipoDocumento (2.1.1.1) e, in ogni riga, il campo AliquotaIVA (2.2.1.12).

Si vede prima dell'invio?

Sì: basta leggere il file.

Vale per: solo le fatture ordinarie.

00475 Manca la partita IVA del cliente per il tipo documento

Testo ufficiale

«per il valore indicato nell'elemento 2.1.1.1 <TipoDocumento> deve essere presente l'elemento 1.4.1.1 <IdFiscaleIVA> del cessionario/committente».

Cosa vuol dire

Per alcuni tipi di documento la partita IVA del cessionario/committente è obbligatoria, e qui manca. Le specifiche elencano i tipi: TD16, TD17, TD18, TD19, TD20, TD22, TD23, TD28 e TD29.

Dove guardare nel file

Il campo TipoDocumento (2.1.1.1) e, nei dati del cessionario/committente, il campo IdFiscaleIVA (1.4.1.1).

Si vede prima dell'invio?

Sì: basta leggere i due campi del file.

Vale per: solo le fatture ordinarie.

00476 Fornitore e cliente entrambi con paese diverso da IT

Testo ufficiale

Fatture ordinarie: «gli elementi 1.2.1.1.1 <IdPaese> e 1.4.1.1.1 <IdPaese> non possono essere entrambi valorizzati con codice diverso da IT».

Fatture semplificate: «gli elementi 1.2.1.1 <IdPaese> e 1.3.1.1.1 <IdPaese> non possono essere entrambi valorizzati con codice diverso da IT».

Cosa vuol dire

Sia il cedente sia il cessionario hanno un identificativo fiscale con paese diverso da IT. Le specifiche dicono che una fattura così non è ammessa.

Dove guardare nel file

Il campo IdPaese nei dati del cedente/prestatore e in quelli del cessionario/committente.

Si vede prima dell'invio?

Sì: basta leggere i due campi del file.

Vale per: fatture ordinarie e semplificate.

00477 Dichiarazione d'intento invalidata

Testo ufficiale

«fattura recante titolo di non imponibilità ai fini IVA ai sensi dell'art. 8, comma 1, lett. c) DPR 26 ottobre 1972, n. 633, con Dichiarazione d'intento invalidata».

Cosa vuol dire

La fattura è emessa senza IVA sulla base di una dichiarazione d'intento, e quella dichiarazione risulta invalidata. Le specifiche non aggiungono altro su questo codice.

Dove guardare nel file

Nei dati della fattura che riportano gli estremi della dichiarazione d'intento.

Si vede prima dell'invio?

No. Lo stato della dichiarazione d'intento lo conosce l'Agenzia delle Entrate, non è nel file.

Vale per: il testo ufficiale non lo indica.
