Come aprire e visualizzare una fattura elettronica XML o P7M

Una fattura elettronica arriva come file XML, a volte come P7M, e se lo apri con un doppio clic vedi righe di codice invece di una fattura. Questa guida mostra due modi per leggerla e come salvarla in PDF.

Perché vedi solo codice

Il file XML contiene i dati della fattura in un formato pensato per essere letto da un programma, non da una persona. Per leggerlo serve un visualizzatore che lo trasformi in una pagina ordinata.

XML e P7M

L'XML è il file della fattura. Il P7M è lo stesso XML dentro una busta di firma digitale: il nome finisce con .p7m, per esempio .xml.p7m. Per leggerlo la busta va tolta, e alcuni visualizzatori lo fanno da soli.

Modo 1: il servizio gratuito dell'Agenzia delle Entrate

L'Agenzia mette a disposizione un servizio di consultazione gratuito. Se hai una partita IVA, nel portale «Fatture e Corrispettivi», box «Consultazione», voce «Fatture elettroniche e altri dati Iva», dalla lente di ingrandimento puoi vedere i dati della fattura o scaricare il file. Per i consumatori finali e gli enti non commerciali, nell'area riservata si va su Servizi, Consultazioni e Ricerca, Fatturazione Elettronica: «Visualizza file fattura» mostra la fattura senza gli eventuali allegati, «Download file fattura» scarica l'XML con gli allegati. Serve l'accesso con SPID, CIE o CNS, oppure con le credenziali Entratel o Fisconline.

Fonti, lette il 10/11/2026: la pagina «Consultare le fatture elettroniche» dell'Agenzia delle Entrate (aggiornata al 24/09/2025) e la guida «La fattura elettronica e i servizi gratuiti dell'Agenzia delle Entrate» (dicembre 2025).

Modo 2: Fattura elettronica in PDF di Datace

  1. Apri lo strumento: non serve installare nulla né registrarsi.
  2. Scegli i file: fatture XML, P7M o uno ZIP con più fatture.
  3. Guarda l'anteprima: l'elenco mostra le fatture lette e l'anteprima del PDF.
  4. Scarica il PDF di una fattura, oppure tutte insieme in uno ZIP.

Il file è elaborato dal browser e non viene inviato a Datace. Tutto sullo strumento nella pagina Fattura elettronica in PDF.

Più fatture insieme

Se hai uno ZIP con molte fatture, scegli lo ZIP: lo strumento legge i file XML e P7M che contiene e ignora gli altri. Gli ZIP dentro altri ZIP non vengono letti.

Cosa mostra il PDF e cosa no

Cedente e cessionario, numero, data e tipo del documento, righe con gli sconti, riepilogo IVA, totale, pagamenti e dati di trasmissione. I codici (tipo di documento, modalità di pagamento, natura, regime fiscale e altri) sono spiegati con le descrizioni dello schema ufficiale dell'Agenzia delle Entrate. Ciò che il file contiene e il PDF non mostra, per esempio alcuni dati del trasporto, compare nell'avviso «Non mostrato nel PDF» della pagina e in fondo al PDF, sotto «Nel file ma non in questo PDF». Gli allegati sono elencati con nome, formato e descrizione.

Se il file è firmato, il PDF lo segnala ma non verifica la firma.

Gli allegati compaiono con nome, formato e descrizione: per averne il contenuto, scarica l'XML dal servizio dell'Agenzia.

Il PDF e il file XML

Il file della fattura è l'XML. Nella sua guida «La fattura elettronica e i servizi gratuiti» (dicembre 2025), l'Agenzia delle Entrate ricorda, a proposito della fattura preparata con il suo servizio e salvata in PDF, che «il file da inviare al SdI è quello XML». Il PDF di Datace è una visualizzazione leggibile: non sostituisce l'XML.

Problemi comuni

  • Il file non si legge: lo strumento lo dice in un avviso e, nell'elenco, lo segna «Non letto» con il motivo (per esempio «Il file supera 10 MB.» o «Non è una fattura elettronica»). Controlla che sia una fattura elettronica XML o P7M.
  • Il PDF non mostra un dato che mi serve: la pagina elenca i dati non mostrati sotto «Non mostrato nel PDF» e in fondo al PDF, sotto «Nel file ma non in questo PDF».
  • Il file è firmato: il PDF lo segnala ma non verifica la firma.

Domande frequenti

Come si apre una fattura elettronica XML?

Con il servizio gratuito dell'Agenzia delle Entrate, oppure scegliendo il file in Fattura elettronica in PDF di Datace, che lo mostra come PDF leggibile nel browser.

Cos'è un file P7M?

È il file XML della fattura dentro una busta di firma digitale. Lo strumento di Datace toglie la busta e legge la fattura.

Posso aprire una fattura XML senza installare programmi?

Sì: Fattura elettronica in PDF funziona nel browser, senza installare nulla né registrarsi.

Come salvo una fattura XML in PDF?

Scegli il file nello strumento e premi «Scarica PDF». Con più fatture puoi scaricarle tutte in uno ZIP.

Il PDF sostituisce l'XML?

No: il file della fattura resta l'XML.
