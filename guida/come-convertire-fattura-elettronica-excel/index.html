Come convertire una Fattura Elettronica XML in Excel

Come trasformare le fatture elettroniche XML e i file firmati .p7m in un file Excel con fornitori, clienti, righe, riepiloghi IVA e scadenze, controllando a schermo i totali prima di scaricare.

Perché convertire le fatture elettroniche XML in Excel

In Italia le fatture tra imprese, verso i consumatori e verso la Pubblica Amministrazione viaggiano quasi tutte come file XML nel formato FatturaPA. Ogni file contiene il fornitore (cedente o prestatore), il cliente (cessionario o committente), le righe, i riepiloghi IVA per aliquota e le condizioni di pagamento.

Il formato è pensato per i programmi, non per essere letto. In Excel le stesse fatture si sommano per aliquota, si filtrano per fornitore, si ordinano per scadenza e si confrontano con la contabilità. Con Fattura elettronica in Excel di Datace lo fai nel browser, in pochi passaggi.

Cosa serve prima di iniziare

  • Le fatture in XML o firmate .xml.p7m: fino a 50 file per volta, ciascuno fino a 10 MB e 100 MB in tutto. Se le hai in uno ZIP, estrai prima i file
  • Chrome, Edge, Firefox, Brave oppure Opera (Safari, iPhone e iPad non sono ancora supportati)
  • Una connessione per aprire lo strumento: la prima volta il browser scarica circa 15 MB, poi di solito li tiene

Vanno bene i file scaricati dal portale «Fatture e Corrispettivi», arrivati via PEC o esportati dal gestionale, nel formato FatturaPA. Nello stesso invio puoi mettere anche le notifiche e i file di metadati del Sistema di Interscambio.

Passo 1: apri Fattura elettronica in Excel

Apri Fattura elettronica in Excel. Non serve installare nulla né registrarsi: la pagina si apre con l'area in cui scegliere i file.

Passo 2: carica i file XML o .p7m

Trascina i file nell'area centrale, oppure cliccala per sceglierli dal computer. Puoi mescolare XML semplici e .p7m, fornitori e periodi diversi. Un file che contiene un lotto di più fatture viene diviso da solo, una fattura per riga. Il file è elaborato dal browser e non viene inviato a Datace.

Passo 3: controlla i dati a schermo

Prima di scaricare, la pagina mostra l'anteprima dei documenti letti e un riepilogo: numero di documenti, imponibile, IVA e totale, al netto delle note di credito, con tre grafici per fornitore o cliente, per mese e per aliquota IVA. Sotto compaiono gli avvisi: doppioni, documenti in altra valuta e documenti di altro tipo, come acconti o autofatture, che non entrano nei totali. Quali tipi vengono sommati lo spiega la guida sul riepilogo IVA degli acquisti. I file che lo strumento non riesce a leggere li elenca con il motivo.

Passo 4: scarica l'Excel

Premi Elabora e scarica Excel. Il file ha cinque fogli:

  • Riepilogo Fatture: una riga per ogni fattura, con tipo di documento, numero, data, fornitore e cliente con partita IVA o codice fiscale, imponibile, IVA, totale, valuta, data di scadenza più lontana, CUP, CIG, numero d'ordine e causale. Anche ogni file di metadati SdI ha qui la sua riga, con tipo «Metadato SdI»
  • Dettaglio Righe: ogni riga di ogni fattura, con descrizione, quantità, unità di misura, prezzo unitario e totale, aliquota IVA e natura
  • Riepilogo IVA: una riga per ogni aliquota di ogni fattura, con imponibile, imposta, natura, esigibilità IVA, tipo di documento e fornitore
  • Notifiche SdI: le ricevute del Sistema di Interscambio presenti tra i file (RC, NS, MC, EC, SE, DT, AT), con esito e nome della fattura a cui si riferiscono
  • Allegati: l'elenco dei documenti allegati alle fatture, con nome e formato

Gli importi sono quelli scritti nel file XML: le note di credito restano con il segno del file, che alcuni emittenti scrivono positivo e altri negativo. Il simbolo dell'euro compare solo sui documenti in euro. Con Scarica tutto in ZIP ricevi, insieme all'Excel, l'XML di ogni file letto (per i .p7m quello estratto dalla firma) e gli allegati, pronti da aprire.

Per sommare imponibile e IVA per aliquota delle fatture ricevute, leggi la guida su come ottenere il riepilogo IVA degli acquisti dalle fatture XML in Excel.

Se vuoi solo leggere una fattura o salvarla in PDF, leggi la guida su come aprire una fattura elettronica XML o P7M.

Problemi comuni e come risolverli

Il file .p7m non si apre sul computer

Il .p7m è una busta di firma digitale (CAdES) che contiene l'XML della fattura. Per aprirlo con un doppio clic serve un programma di verifica della firma. Qui non serve: carica direttamente il .xml.p7m e lo strumento ne estrae l'XML.

Il file non viene riconosciuto come fattura

Lo strumento legge il tracciato FatturaPA. Un XML di altro tipo viene scartato e la pagina lo elenca tra i file non elaborati. Le fatture semplificate e i corrispettivi sono riconosciuti ma non letti: anche loro vengono scartati, con il motivo.

Celle vuote nell'Excel

Molti campi della fattura sono facoltativi, per esempio la scadenza, il CIG o la natura IVA. Se chi ha emesso la fattura non li ha compilati, la cella resta vuota: lo strumento riporta solo ciò che è scritto nel file.

Fattura elettronica in Excel supporta

  • ✓ Fatture XML FatturaPA (FPR12 e FPA12)
  • ✓ File firmati .xml.p7m (CAdES)
  • ✓ Lotti con più fatture nello stesso file
  • ✓ Notifiche e metadati del Sistema di Interscambio
  • ✓ Fino a 50 file per volta, 100 MB in tutto
  • ✓ Excel su 5 fogli, oppure ZIP con XML e allegati

Domande frequenti

Come si converte una Fattura Elettronica XML in Excel?

Apri Fattura elettronica in Excel, scegli i file XML o .p7m, controlla l'anteprima e premi Elabora e scarica Excel. Ricevi un file su cinque fogli, senza installare nulla.

Come apro un file .p7m di una fattura?

Il .xml.p7m è una fattura XML con la firma digitale (CAdES). Fattura elettronica in Excel ne estrae l'XML e ne legge i dati, senza programmi per la verifica della firma. Con lo ZIP scarichi anche l'XML estratto.

I miei dati vengono salvati o condivisi?

Le fatture vengono lette e convertite dal tuo browser: Datace non le riceve, quindi non le salva e non le condivide. Non esiste un archivio e non c'è registrazione.

Posso caricare più fatture insieme?

Sì, fino a 50 file per volta, ciascuno fino a 10 MB e 100 MB in tutto. Un file XML può contenere più fatture (lotto): ognuna ha la sua riga nell'Excel.

Quali tipi di documento sono supportati?

Tutti i tipi del tracciato ordinario, da TD01 a TD06 e da TD16 a TD29: fatture, acconti, note di credito e di debito, parcelle, integrazioni, autofatture e fatture differite. Nell'Excel ogni tipo ha la sua descrizione. Le fatture semplificate (TD07, TD08, TD09) e i corrispettivi non vengono letti: lo strumento li scarta indicando il motivo.

Nell'Excel ci sono le modalità di pagamento e le rate?

No. Il foglio Riepilogo Fatture riporta, per ogni fattura, la data di scadenza più lontana; modalità e importi delle singole rate non sono nel file. Per uno scadenzario con ogni rata e il file dei bonifici ai fornitori c'è Fatture XML in bonifici.
