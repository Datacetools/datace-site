Come legge il file

  • Un elenco di oggetti diventa una riga per oggetto. Se il file contiene più elenchi, scegli da quale partire.
  • Anche i file JSON Lines, con un oggetto per riga, vanno bene.
  • I campi dentro altri campi diventano colonne con il punto, per esempio indirizzo.citta.
  • Gli elenchi di valori semplici stanno in una cella, separati da «; ».
  • Un elenco di oggetti dentro una riga resta nella cella come testo JSON, e lo strumento te lo dice.

Numeri, date e testo

I numeri fino a 15 cifre restano numeri, senza arrotondamenti. Quelli più lunghi restano testo, com'è scritto nel file. Le stringhe restano testo, anche 00123. Le date scritte come 2026-11-13 diventano date di Excel. Vero e falso diventano VERO e FALSO, e un valore nullo diventa una cella vuota.

Limiti

Fino a 50 MB per file, 1.048.576 righe (il massimo di Excel) e 16.384 colonne. Una cella oltre i 32.767 caratteri dà un errore. Se il JSON non è valido lo strumento indica la riga e la colonna dell'errore. Gli elenchi di oggetti dentro una riga non diventano un secondo foglio.

FAQ

Domande frequenti

Come apro un file JSON in Excel?
Scegli il file nello strumento: Datace lo trasforma in una tabella e scarichi un Excel.
Cosa succede ai campi dentro altri campi?
Diventano colonne con il punto nel nome, per esempio indirizzo.citta.
Perché un numero lungo resta testo?
Excel conserva al massimo 15 cifre: oltre, lo strumento lo lascia testo come nel file, così non cambia valore.
I miei file vengono inviati a un server?
No. Il file è elaborato dal browser e non viene inviato a Datace.
Posso incollare il testo invece di scegliere il file?
Sì: incolla il testo nella casella e ottieni la stessa anteprima.
È gratuito?
Sì, senza registrazione.
