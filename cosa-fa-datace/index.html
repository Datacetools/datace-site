Cosa fa Datace dei tuoi file

Questa pagina descrive cosa succede ai file quando usi gli strumenti di Datace. Se qualcosa cambia, la aggiorniamo.

Cosa succede al file

F24 PDF in Excel, Fattura elettronica in Excel e Bonifici massivi XML: elaborazione nel browser. Il file viene letto e convertito dal browser, sul tuo computer. Non viene inviato a Datace, che quindi non lo riceve e non ne ha copia.

In nessun caso usiamo i file per altri scopi né per addestrare modelli di intelligenza artificiale.

Cosa registriamo

Datace non registra i file né il loro contenuto. Per tutto il sito usiamo Umami, senza cookie: conta le pagine viste e l'uso degli strumenti (apertura, scelta dei file, esito), non il contenuto dei file. Il sito è ospitato su GitHub Pages, che registra l'indirizzo IP dei visitatori per motivi di sicurezza.

Chi interviene

Il sito e gli strumenti sono ospitati su GitHub Pages (Stati Uniti). Statistiche: Umami Cloud. Messaggi di feedback e risposte della pagina «Raccontaci come lavori»: Formspree. Dettagli nell'informativa.

Raccontaci come lavori

Pagina «Raccontaci come lavori». Compilarla è facoltativo. Se la compili, raccogliamo le risposte (ruolo, numero di aziende o clienti, documenti che tratti, testo libero) e, solo se vuoi, la tua email. Le usiamo per migliorare gli strumenti di Datace. Se lasci l'email e dai il consenso, potremo scriverti per approfondire le risposte. Non inserire dati di clienti o dipendenti. Le risposte arrivano tramite Formspree (USA) e sono conservate al massimo 24 mesi; puoi chiederne la cancellazione scrivendo a info@datacetools.com. Puoi revocare il consenso in qualsiasi momento.

Cosa non facciamo

Niente account. Niente vendita dei dati. Niente pubblicità. Niente profili.

I limiti

Nessun servizio online è sicuro al cento per cento. Il file resta sul tuo computer, ma computer, browser ed estensioni installate restano sotto la tua responsabilità. In ogni caso non usare dati sanitari o altri dati particolari.
