Fattura elettronica in PDF

Apri e converti fatture XML, P7M o ZIP in PDF leggibili, direttamente nel browser.

Il file è elaborato dal browser e non viene inviato a Datace. Gratuito, senza registrazione.

Il PDF

Cosa mostra il PDF

Cedente e cessionario, numero, data e tipo del documento, righe con gli sconti, riepilogo IVA, totale, pagamenti e dati di trasmissione. I codici (tipo di documento, modalità di pagamento, natura, regime fiscale e altri) sono spiegati con le descrizioni dello schema ufficiale dell'Agenzia delle Entrate. Ciò che il file contiene e il PDF non mostra, per esempio alcuni dati del trasporto, compare nell'avviso «Non mostrato nel PDF» della pagina e in fondo al PDF, sotto «Nel file ma non in questo PDF». Gli allegati sono elencati con nome, formato e descrizione.

Se il file è firmato, il PDF lo segnala ma non verifica la firma.

Limiti

Fino a 10 MB per ogni file XML. In una scelta, fino a 50.000 file contando quelli dentro gli ZIP, e 1 GB in tutto; gli ZIP dentro altri ZIP non vengono letti.

Per aprire una fattura anche con il servizio dell'Agenzia delle Entrate, leggi la guida su come aprire una fattura elettronica XML o P7M.

FAQ

Domande frequenti

Come si apre una fattura elettronica XML?
Scegli il file nello strumento: la pagina lo legge e lo mostra come PDF leggibile. Funziona anche con i file P7M e con gli ZIP che contengono più fatture.
Che differenza c'è tra XML e P7M?
Il P7M è il file XML dentro una busta di firma digitale. Lo strumento toglie la busta e legge la fattura; il PDF dice se il file è firmato ma non verifica la firma.
Posso convertire più fatture insieme?
Sì: scegli più file o uno ZIP. Vedi l'elenco con l'anteprima e scarichi i PDF uno alla volta o tutti insieme in uno ZIP.
I miei file vengono inviati a un server?
No. Il file è elaborato dal browser e non viene inviato a Datace.
Il PDF sostituisce il file XML?
No. Il PDF è una visualizzazione leggibile del contenuto; il file della fattura resta l'XML. Lo ricorda anche l'Agenzia delle Entrate nella guida «La fattura elettronica e i servizi gratuiti» (dicembre 2025): «il file da inviare al SdI è quello XML».
Cosa non mostra il PDF?
Mostra i dati principali e i codici spiegati. Alcuni dati meno comuni, per esempio quelli del trasporto, non sono nel PDF: la pagina li elenca sotto «Non mostrato nel PDF» e in fondo al PDF, sotto «Nel file ma non in questo PDF», così sai cosa manca. Degli allegati compaiono nome, formato e descrizione, non il contenuto.
È gratuito?
Sì, senza registrazione.
